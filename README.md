# 知行起名 · 微信小程序

一个以「中华姓名学 + 古典文学」为内核的起名工具小程序，覆盖起名核心与文化工具箱两大板块，全部功能免费，会员提供八字排盘深度解读。

## 功能矩阵

### 起名核心
- 古典诗词起名（诗经 / 楚辞 / 唐诗 / 宋词，40 句名句取义）
- 八字五行起名（按喜用神五行补益生成佳名）
- 双胞胎 / 龙凤胎起名（共享字 / 诗词对仗）
- 兄弟姐妹起名（字辈 / 主题成组）
- 定字起名（给定一字巧配佳名）
- 姓名测试（五格 / 三才 / 五行 / 音律）

### 文化工具箱 · 瑞士军刀
- 字典 · 单字精解（读音 / 五行 / 康熙笔画 / 寓意 / 典籍出处）
- 生肖起名（喜忌字根 / 三合六合相冲 / 按喜用五行推荐）
- 三才五格（五格数理 / 81 数理 / 三才配置）
- 藏头诗（姓名嵌首 · 五言 / 七言）
- 谐音避坑（连读翻车 / 多音字 / 生僻复杂字 / 气质倾向）
- 姓名配对（五行互补 / 五格笔画 / 默契指数）
- 每日美名（按当日日期确定性轮播经典雅名）
- 百家姓溯源（起源 / 郡望 / 历史名人）

### 深度服务
- 八字排盘（四柱 / 五行旺衰 / 大运 / 喜用神 / 白话详解，深度解读为会员专享）
- 会员中心（权益 / 开通 / 三档咨询）

## 技术栈
- 微信小程序原生（.wxml / .wxss / .js / .json）
- 纯逻辑引擎层（utils + data）与 UI 解耦，Node 可独立跑单元测试
- 国风视觉：宣纸米 `#F5F1E8` + 朱红 `#C0392B` + 金棕 `#9C6B3C`

## 工程结构
```
app.js / app.json / app.wxss / project.config.json / sitemap.json
data/     100 好字库 · 诗词库 · 常用字扩展 · 生肖 · 谐音 · 百家姓 · 每日美名
utils/    bazi 八字引擎 · wuge 五格 · namegen 生成 · kit 扩展工具 · util · store
pages/    17 个页面，每页 js/json/wxml/wxss 四件套
tools/    qa_bazi / qa_all / qa_kit / qa_pages · make_icons（tabBar 图标生成）
images/   tabBar 图标（由 make_icons.js 生成，未入库）
```

## 本地运行 / 发布
1. 下载「微信开发者工具」，导入本目录（project.config.json 已就位）。
2. 将 project.config.json 的 `appid` 替换为你的真实 AppID（或先用 `touristappid` 测试号预览）。
3. 工具内预览 17 页 → 上传代码 → 提交审核 → 发布。

## 测试
```bash
node tools/qa_all.js     # 起名引擎联调
node tools/qa_kit.js     # 瑞士军刀扩展工具
node tools/qa_pages.js   # 页面逻辑（模拟 wx + Page）
```

## 合规
所有姓名学 / 五行 / 五格分析均属中华传统文化赏析，纯属娱乐，不作任何命运断言或吉凶承诺；全站无算命 / 改命 / 转运 / 招财 / 辟邪表述。
